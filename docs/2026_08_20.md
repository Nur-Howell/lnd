# Bash Network Diagnostic Script: Code Breakdown & Architecture Guide

This document contains the fully refactored script and a comprehensive, line-by-line explanation of the architecture, data flow, and Bash mechanisms used within it. 

---

## 1. The Full Refactored Script

```bash
#!/bin/bash

# --- Data Store (Global Scope) ---
declare -A NET_DATA

fetch_interface_info() {
    # Silence potential stderr outputs with 2>/dev/null
    local interfaces=($(ip link 2>/dev/null | grep -E '^[0-9]+:' | awk '{print $2}' | tr -d ':' | grep -v '^lo$'))
    NET_DATA["COUNT"]="${#interfaces[@]}"
    NET_DATA["LIST"]="${interfaces[*]}"

    # Store host IP (silence potential errors if hostname command fails)
    NET_DATA["HOST_IP"]=$(hostname -I 2>/dev/null)

    # Loop through interfaces
    for int in "${interfaces[@]}"; do
        NET_DATA["${int}_IPV4"]=$(ip -4 addr show "$int" 2>/dev/null | grep -E 'inet [0-9]' | awk '{print $2}')
        NET_DATA["${int}_IPV6"]=$(ip -6 addr show "$int" 2>/dev/null | grep -E 'inet6 ' | awk '{print $2}')

        local stats=$(ip -s link show "$int" 2>/dev/null)

        local rx_line=$(echo "$stats" | grep -A 1 "RX:" | tail -n 1)
        NET_DATA["${int}_RX_BYTES"]=$(echo "$rx_line" | awk '{print $1}')
        NET_DATA["${int}_RX_PACKETS"]=$(echo "$rx_line" | awk '{print $2}')

        local tx_line=$(echo "$stats" | grep -A 1 "TX:" | tail -n 1)
        NET_DATA["${int}_TX_BYTES"]=$(echo "$tx_line" | awk '{print $1}')
        NET_DATA["${int}_TX_PACKETS"]=$(echo "$tx_line" | awk '{print $2}')
    done
}

host_show() {
    printf "Current Host IP: %s\n\n" "${NET_DATA["HOST_IP"]}"
}

interfaces_show() {
    printf "Interfaces:\n%s\n" "${NET_DATA["LIST"]}"
    printf "Interface Count: %s\n" "${NET_DATA["COUNT"]}"
}

interfaces_address_show() {
    local interfaces=(${NET_DATA["LIST"]})

    echo "=== IP Addresses Overview ==="
    for int in "${interfaces[@]}"; do
        echo "Interface: $int"
        echo "  IPv4: ${NET_DATA["${int}_IPV4"]:-None}"
        echo "  IPv6: ${NET_DATA["${int}_IPV6"]:-None}"
        echo ""
    done
}

packets_show() {
    local interfaces=(${NET_DATA["LIST"]})

    echo "=== Network Traffic Overview ==="
    for int in "${interfaces[@]}"; do
        echo "Interface: $int"
        echo "  RX: ${NET_DATA["${int}_RX_BYTES"]:-0} bytes (${NET_DATA["${int}_RX_PACKETS"]:-0} packets)"
        echo "  TX: ${NET_DATA["${int}_TX_BYTES"]:-0} bytes (${NET_DATA["${int}_TX_PACKETS"]:-0} packets)"
        echo ""
    done
}

# --- Execution ---
fetch_interface_info
host_show
interfaces_show
interfaces_address_show
packets_show
```

## 2. Line-by-Line Breakdown

### The Global Data Store

```bash
declare -A NET_DATA
```
* **`declare`**: A Bash built-in command used to set variable attributes and properties.
* **`-A`**: Tells Bash to create an **Associative Array** (also known as a hash map or dictionary in other languages). 
  * *Standard Array (`declare -a`)*: Uses numbers as indexes (`ARRAY[0]`, `ARRAY[1]`).
  * *Associative Array (`declare -A`)*: Uses string keys (`ARRAY["eth0_IPV4"]`, `ARRAY["COUNT"]`).
* **Placement**: Declaring this at the top level of the script (outside functions) gives it **Global Scope**. Any function in the script can modify or read values from `NET_DATA` without needing to pass variables around.

### Gathering the Interface Names

```bash
local interfaces=($(ip link 2>/dev/null | grep -E '^[0-9]+:' | awk '{print $2}' | tr -d ':' | grep -v '^lo$'))
```
This single line is a pipeline that processes text from left to right:
1. **`local interfaces=( ... )`**: Restricts the `interfaces` variable so it only exists inside `fetch_interface_info()`. The `=()` converts the output into a Bash array.
2. **`ip link`**: Queries the Linux kernel's network subsystem to list all network interface controllers.
3. **`grep -E '^[0-9]+:'`**: Filters the output down to only the main header lines for interfaces (e.g., `1: lo:` or `2: eth0:`).
4. **`awk '{print $2}'`**: Extracts and outputs only the **second column** (which contains the interface name, e.g., `eth0:`).
5. **`tr -d ':'`**: Removes the trailing colon from the string (`eth0:` becomes `eth0`).
6. **`grep -v '^lo$'`**: Inverts the match (`-v`) to cleanly strip out the loopback interface (`lo`).

### Populating Global Keys & Array Operations

```bash
NET_DATA["COUNT"]="${#interfaces[@]}"
NET_DATA["LIST"]="${interfaces[*]}"
```
* **`${#interfaces[@]}`**: Calculates the total number of non-loopback interfaces found and assigns that integer into the `COUNT` key.
* **`"${interfaces[*]}"`**: Expands all array elements into a single, space-separated string (e.g., `"eth0 wlan0"`) and stores it in the `LIST` key.

### Extracting IPs in the Loop

```bash
for int in "${interfaces[@]}"; do
    NET_DATA["${int}_IPV4"]=$(ip -4 addr show "$int" 2>/dev/null | grep -E 'inet [0-9]' | awk '{print $2}')
```
1. **`ip -4 addr show "$int"`**: Queries `iproute2` for IPv4 addresses assigned *only* to the specific interface in the current loop iteration.
2. **`grep -E 'inet [0-9]'`**: Filters for lines containing `inet` followed by a number.
3. **`awk '{print $2}'`**: Grabs column 2, which contains the IP and subnet mask in CIDR notation (e.g., `192.168.1.50/24`).
4. **Assignment**: Saves the output directly into `NET_DATA` using a dynamic key built from the interface name (e.g., `NET_DATA["eth0_IPV4"]`).

### Extracting RX and TX Bytes/Packets

```bash
local stats=$(ip -s link show "$int" 2>/dev/null)
local rx_line=$(echo "$stats" | grep -A 1 "RX:" | tail -n 1)
NET_DATA["${int}_RX_BYTES"]=$(echo "$rx_line" | awk '{print $1}')
```
1. **`ip -s link show "$int"`**: The `-s` flag asks for statistics. Saving this into a local variable (`stats`) means we query the kernel once, rather than running `ip -s link` twice (once for RX, once for TX).
2. **`grep -A 1 "RX:"`**: Returns the line that matches `"RX:"` **plus 1 line immediately following it**.
3. **`tail -n 1`**: Grabs the last line of that 2-line block, isolating the raw numerical data.
4. **`awk '{print $1}'`**: Extracts Column 1 (total received bytes) and assigns it to `NET_DATA["eth0_RX_BYTES"]`.

### Display Functions & Parameter Expansion

```bash
echo "  IPv4: ${NET_DATA["${int}_IPV4"]:-None}"
```
* **Parameter Expansion with a Fallback Default (`:-`)**: 
  * Syntax: `${VAR:-default}`
  * *Meaning*: If `NET_DATA["eth0_IPV4"]` exists and is not empty, print its value. **If it is empty or unset, print `"None"` instead.** This prevents the output from displaying weird blank spaces when an interface doesn't have an assigned IP.
