
> **Description:** Executes `hostname -I` to retrieve all network addresses assigned to the host and assigns the resulting string to the `current_host` variable.

---


> **Description:** Prints the value of `$current_host` to standard output, followed by two newline characters.

---

```bash
int_status=$(ip link | grep -E '^[0-9]+:' | awk '{print $2}' | tr -d ':') # show interfaces
```
> **Description:** 
> 1. `ip link` lists all network interfaces.
> 2. `grep -E '^[0-9]+:'` filters for lines starting with an interface index (e.g., `1: lo:`).
> 3. `awk '{print $2}'` extracts the second column containing the interface name.
> 4. `tr -d ':'` strips out the trailing colon attached to the name.
> 5. Saves the space/newline-separated list of interface names into `int_status`.
