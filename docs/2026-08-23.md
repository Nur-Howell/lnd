## Menu Script
Functions:
```
press_enter()
incorrect_msg()
menu()
```
## press_enter()
Prompts user to press **Enter** on their keyboard to continue the program.

## incorrect_msg()
Displays a message "Incorrect selection, try again!" after user inputs the wrong key.

## menu()
Core UI that contains the logic for user interfacing logic. Comprises of the `while` loop for indefinite program running until the user selects the `Exit` option that closes the program. Also displays the text of the menu. Currently has the `interfaces.sh` related functions namely `info_show` that displays the respective information.
